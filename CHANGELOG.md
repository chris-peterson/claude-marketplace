# What's new

Highlights for the bridge.ai suite as a whole, by date. `suite/build-whats-new.py`
merges these with every plugin release and artifact change into
`docs/whats-new.md`, which the What's new page and its RSS feed read.

## 2026-11-11

- **released:** [bridge.ai 2.0](https://chris-peterson.github.io/#/blog/2026-11-11-bridge-ai-2): new plugins rig, fathom, masthead, and sonar, plus a new mark.
- **new plugin:** [rig](https://chris-peterson.github.io/rig/#/): launch Claude Code with a named set of plugins, your local checkouts pinned in, and the sandbox when you want it.
- **new plugin:** [fathom](https://chris-peterson.github.io/fathom/#/): keep the facts of a piece of work in one record, and write each reader their own document from it.
- **preview:** [masthead](https://chris-peterson.github.io/masthead/#/): stand up a documentation hub for a repo and keep it current.
- **preview:** [sonar](https://chris-peterson.github.io/sonar/#/): search everything a session can reach; shallow matches now, deeper ones by your next turn.
- **changed:** the catalog groups plugins by the job they help with: plan the passage, stay safe, keep oriented, reach your waypoints, chart the waters, and leave standing orders.
- **changed:** the mark is a helm, one spoke per job.
- **released:** [anchor 2.0](https://chris-peterson.github.io/anchor/#/): diff reviews open in revdiff, notes land on the hunks you'd ask about, reviews work in rounds, and stacks are first class. `diff.tool` is ignored now, and revdiff 1.14+ is required.
- **released:** [ClaudeWatch 1.0](https://chris-peterson.github.io/ClaudeWatch/#/): your rule changes survive upgrades, `/ClaudeWatch:unattended` for stepping away, more rule sets for commands with no undo, and it guards itself against the agent. `/ClaudeWatch:learn` no longer proposes allow rules.
- **archived:** moor and logbook.
