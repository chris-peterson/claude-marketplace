Tools for navigating the uncharted waters of AI-assisted development.

Claude writes code faster than you can track. These plugins keep you in charge: block unsafe commands, keep your place across parallel work, review the diff and land clean commits and change requests, and build to a plan, keeping what you learn.

Install

Register the marketplace once. After that, install any plugin with claude plugin install <name>@chris-peterson — each one below carries its exact command and a link to full docs.
